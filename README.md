**MOAI MODEL WORK-FLOW:**
- Use ChituBox or LycheeSlicer for arranging and supporting your models.
- Export your arranged and supported model as an OBJ file.
- Open the file in MeshMixer or OrcaSlicer and repair the model
- Export the object as a new STL file. (Cura often fails with OBJ files)
- Slice using CURA 4.7 with the profiles that are included in this repository.
- Save the gcode file to the "gcode" folder on the SD card and put into the Moai.
- In "SETUP "advanced_setting" set the "XY Speed Set" for the cure speed of the resin. (Print-speed Multiplier)
